# Gate counter

Which gate caught a real problem. Counting period: YYYY-MM-DD to YYYY-MM-DD (one month).
How to use it: the `produce-video` skill, `references/learning-loop.md`.

## Rules

- **One line per real catch.** A false alarm is not a catch; the work must have needed a fix.
- At the end of the period, count the catches per gate and fill the table at the bottom.
- **A code gate that caught nothing is loosened** (a wider threshold, a faster mode, or run less often).
  **An agent gate that caught nothing is removed** from the line. The creator decides; write the decision down.
- A gate added during the period gets its own month.
